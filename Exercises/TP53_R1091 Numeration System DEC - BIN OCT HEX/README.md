## __Instructions__

Follow the instructions below to compile and execute the program.

### __Compilation and Execution__

1. Open a terminal and navigate to the program's root folder. From the directory where this instruction is located, run the following command in the terminal:

🔸️ `make`

2. If you receive an error message via terminal with the following report:  
`bash: make: command not found` run the following commands in the terminal:

🔸️ `sudo apt-get update && sudo apt-get upgrade`  
🔸️ `sudo apt-get install make`

3. Know the results of the program executing the following command in the terminal:

🔸️ `make run`
